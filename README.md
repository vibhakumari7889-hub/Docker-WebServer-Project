# Docker Web Server

A simple web server deployed using Docker and Nginx.

## Project Overview

This project demonstrates how to run a basic web application inside a Docker container using the Nginx web server.

The application is built with HTML and served through Nginx.

## Technologies Used

- HTML
- Docker
- Nginx
